# Fashion Style Families

Choose one family per output. Give it one visible signature and do not average multiple families into generic luxury fashion.

| Family | Signature | Useful contrast | Avoid |
|---|---|---|---|
| Street editorial | hard graphic blocks, condensed type, cropped movement | human softness / graphic interruption | random stickers |
| Quiet luxury | restrained serif, paper field, controlled tailoring | intimacy / distance | gold overload |
| Retro French | wine, cream, film grain, elegant posture | stillness / desire | fake vintage clutter |
| Y2K digital | chrome, translucent plastic, flash, modular type | human / synthetic | chaotic neon |
| Y2K cyber-kawaii idol scrapbook | central glam portrait, mini portrait orbit, deco stickers, fan-zine labels, candy chrome | idol intimacy / digital maximalism | equal-weight clutter, copied fandom branding |
| Gothic romantic | black, oxblood, lace, shadow, narrow light | beauty / concealment | horror clichés |
| Japanese minimal | calm grid, pale field, small type, precise crop | presence / disappearance | empty decoration |
| Art-school collage | torn paper, ink bite, uneven scale, handmade marks | order / disruption | uncontrolled collage |
| Futuristic technical | silver, graphite, interfaces, hard rim light | body / machine | cheap 3D |
| Sports couture | physical tension, performance fabric, directional light | effort / elegance | product-ad cliché |
| Surreal color-block | one impossible scale or color field, simple type | real / artificial | too many effects |
| Documentary runway | candid gesture, practical light, raw texture | spectacle / observation | stock pose |
| Typography-first | title is the main mass, image is cropped evidence | text / body | unreadable type wall |

When the user asks for another style, exclude the latest family, dominant palette, and dominant layout before selecting a new one.
