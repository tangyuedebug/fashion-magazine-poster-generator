# Layered Fashion Poster Workflow

Use layered mode when exact typography, reusable layouts, or a coherent series matters.

## Layer roles

1. **Background/image layer**：人物、服装、场景、光影、构图和留白；keep text minimal or absent.
2. **Typography/graphic layer**：masthead, title, issue number, short labels, rules, color blocks, and texture.
3. **Composite layer**：combine without changing the subject crop, safe area, or visual hierarchy.

## Safe-area rules

- Reserve the text field before generating the image.
- Keep the face, hands, and key garment detail away from dense microtype.
- Align title, metadata, and image edge to one optical grid.
- Use one dominant title interaction: behind the figure, over the garment, cropped by the edge, or placed in a vertical spine.

## When exact text matters

Prefer generating the image/background without small copy, then place exact copy in a layout tool. If a separate typography image is generated, verify spelling and alignment before compositing. Never claim the result is editable unless the layer files were actually saved.

## Deliverables

When the user requests reusable layers, save or return the background layer, typography layer, composite, and the grid/placement notes. When the user requests only a poster, return only the composite and concise art direction.
